CSS Layouts

Los CSS Layouts (diseños o maquetaciones en CSS) son el conjunto de técnicas, propiedades y modelos en hojas de estilo que se utilizan para organizar, posicionar y estructurar los elementos visuales de una página web en relación con la pantalla o el navegador

Animaciones

Las animaciones en CSS son efectos visuales que permiten cambiar gradualmente el estilo de un elemento HTML a lo largo del tiempo, pasando por dos o más estados sin necesidad de usar JavaScript.

Sass

(Syntactically Awesome Style Sheets) es un preprocesador de CSS que extiende las capacidades del lenguaje tradicional al añadir herramientas propias de la programación, como variables, mixins, funciones, bucles y selectores anidados.

¿Qué es CSS?

El lenguaje CSS fue propuesto originalmente por Håkon Wium Lie en 1994 y desarrollado por el consorcio W3C (World Wide Web Consortium). Antes de su llegada, los programadores tenían que definir los colores y fuentes dentro del propio código HTML, lo que hacía que las páginas fueran pesadas y difíciles de mantener.

¿Qué aprenderé en este curso?

¿Qué es CSS GRID?

CSS Grid Layout (o simplemente CSS Grid) es un sistema de diseño bidimensional nativo de CSS que permite crear estructuras de páginas web basadas en filas y columnas al mismo tiempo. A diferencia de las herramientas del pasado (como las tablas o los floats) y de Flexbox (que está diseñado principalmente para una sola dimensión, ya sea fila o columna), CSS Grid te da el control total de ambos ejes.
